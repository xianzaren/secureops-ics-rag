# Reports

- `data_quality_report.md` / `.json`: measured selection statistics for the CVE corpus.
- `evaluation_report.md` / `.json`: measured dense-baseline and hybrid retrieval results.

Reports are generated artifacts intended to be committed with the project so
reviewers can inspect both human-readable results and raw per-case evidence.
Regenerate them after source, chunking, embedding, retrieval, or evaluation-set
changes.
