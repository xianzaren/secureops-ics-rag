# Security policy

## Supported version

Security fixes target the latest revision of the `main` branch.

## Reporting a vulnerability

Do not disclose exploitable issues, credentials, or sensitive OT information in
a public GitHub issue. Use the repository owner's private security contact or
GitHub private vulnerability reporting after the repository is published.

Include:

- affected component and revision;
- reproduction steps with secrets removed;
- expected impact;
- suggested mitigation, if known.

## Operational warning

SecureOps is a demonstration and decision-support system. Do not connect it
directly to a production control network or upload confidential plant documents
without completing an organizational security, privacy, and threat-model review.
